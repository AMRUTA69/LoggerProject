# Simple Logger Application (Java)

A simple Java application that appends timestamped log messages to a text file. It demonstrates the use of `FileWriter` in append mode and try-with-resources for safe file handling.

## ✨ Features

- ✅ Append log messages to a file without overwriting previous logs
- ✅ Automatically adds the current date and time to each log entry
- ✅ Uses try-with-resources for safe file handling
- ✅ Handles IOExceptions gracefully
- ✅ Validates empty messages before logging
